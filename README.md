FleetPulse is an enterprise-grade connected vehicle intelligence platform that continuously converts high-volume vehicle telemetry (100,000+ events/sec) into explainable maintenance risk and business-impact priorities.

---

## 🎯 Product Thesis & Core Differentiator
**"FleetPulse continuously converts connected-vehicle telemetry into explainable maintenance risk and business-impact priorities so fleet managers know which vehicles need attention first and why."**

Instead of overwhelming dispatchers with raw unranked DTCs and sensor thresholds ("alert fatigue"), FleetPulse ranks every vehicle using an operationally grounded mathematical formula:

$$\text{PriorityScore} = \text{RiskProbability} \times \text{ImpactExposure} \times \text{UrgencyFactor}$$

Where:
- **$\text{RiskProbability} \in [0.0, 1.0]$**: Generated by a Gradient-Boosted Tabular Classifier evaluated against simulated ground truth and compared to a deterministic physics baseline.
- **$\text{ImpactExposure} \in [1.0, 10.0]$**: Quantifies vehicle revenue tier, mission criticality, and cargo risk.
- **$\text{UrgencyFactor} \in [1.0, 5.0]$**: Physics rate-of-change modifier (e.g. rapid thermal climb $>1.2^\circ\text{C/min}$ triggers $U = 5.0$).

## 🏗️ Architecture Blueprint

```
Simulator (100K+ Vehicles)
         │
         ▼ (MQTT / HTTP)
  Ingestion Gateway
         │
         ▼
Kafka Topic: telemetry.raw ──► Multi-OEM Normalizer ──► MongoDB (Raw BSON / DLQ)
                                      │
                                      ▼
                           Kafka: telemetry.canonical
                                      │
                                      ▼
                      Stream Processor (Flink Semantics)
                      ├── Event-Time Watermarking (5s)
                      ├── Idempotent Deduplication (1h)
                      └── Sliding Windows (1m, 5m, 15m)
                                      │
             ┌────────────────────────┼────────────────────────┐
             ▼                        ▼                        ▼
ClickHouse (Columnar OLAP)     Redis (Hot State)     PostgreSQL 16 (3NF Core)
(Telemetry history & stats)   (Latest vehicle state) (Work orders, RBAC, audit)
                                      │                        │
                                      └───────────┬────────────┘
                                                  ▼
                                           FastAPI Gateway
                                           (REST + WebSocket)
                                                  │
                                                  ▼
                                       React 18 Command Centre
```

## 🚀 Quickstart & One-Command Local Startup

### 1. Prerequisites
- Docker & Docker Compose
- Python 3.10+ (for local test execution)
- Node.js 20+ (for frontend development)

### 2. Start Full Platform via Docker Compose
```bash
make up
```
Or directly:
```bash
docker compose up -d
```
Access the services:
- **FleetPulse Command Centre**: [http://localhost:3000](http://localhost:3000)
- **FastAPI Interactive Docs (Swagger)**: [http://localhost:8000/api/v1/docs](http://localhost:8000/api/v1/docs)
- **Prometheus Metrics**: [http://localhost:9090](http://localhost:9090)

### 3. Developer Commands
```bash
make test             # Run all 28 unit, integration, and contract tests
make seed             # Generate deterministic 100,000-vehicle seed dataset
make simulate         # Run continuous vehicle telemetry stream
make scenario NAME=thermal_overheat  # Inject named fault scenario
make load             # Run 100,000+ events/sec streaming benchmark
make docs             # Re-generate all empirical evidence reports
```
